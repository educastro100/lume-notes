# Segurança

Para falhas de segurança, use **Security → Report a vulnerability** no repositório do Lume, se o relato privado estiver habilitado. Caso a opção não esteja disponível, abra uma issue solicitando um canal privado, sem anexar a falha explorável, notas, sessões, credenciais ou logs pessoais. Bugs comuns e sugestões podem ser relatados publicamente no [canal de issues](https://github.com/educastro100/lume-notes-releases/issues).

Ao relatar um alerta de antivírus, informe a versão, a origem do download, o nome da detecção e o hash do arquivo se já estiver disponível. Não é necessário restaurar um arquivo bloqueado para obtê-lo. Não publique relatórios completos do Windows contendo dados pessoais.

Os pacotes 0.9.0 e 0.10.0 continuam bloqueados nos scripts de distribuição. Consulte os documentos de auditoria em docs/ e a [política de assinatura](docs/code-signing.md). Não há declaração de que tornar o código público resolve esses alertas.
