# Lume Notes 0.9.0

- Primeiro instalador Windows por usuário, com atalhos e desinstalador.
- Registro no Abrir com e na lista de aplicativos padrão para texto, Markdown, JSON, log e CSV. A escolha do aplicativo padrão continua com o usuário.
- Atualizações pelo aplicativo com download assinado, progresso e opção de instalar depois.
- Botões Verificar atualizações e Escolher padrões do Windows nas configurações.
- Rascunhos, grupos, temas e preferências mantidos entre instalações e atualizações.

O instalador usa o WebView2 Runtime; baixa o componente da Microsoft somente se necessário. O aplicativo continua local, sem conta ou sincronização de notas.
